# Tarefa 5 — Sugestão assistida no importer

## Status

Pendente.

## Objetivo

Usar IA para sugerir tags dentro do vocabulário controlado, mantendo decisão editorial humana na fase inicial.

## Escopo

- fornecer vocabulário permitido ao prompt;
- proibir criação livre de tag;
- registrar justificativa curta para cada sugestão;
- manter sugestões em rascunho ou revisão antes da publicação;
- permitir rejeição e ajuste humano.

## Critérios de pronto

- IA só sugere tags existentes;
- sugestões ficam revisáveis;
- rejeições são possíveis e registráveis;
- prompts seguem a skill local de tagging editorial quando ela existir;
- falha de sugestão não bloqueia importação.
