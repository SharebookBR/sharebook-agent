# Prompt Patterns — Art Director

## Post Sharebook

```text
Use case: ads-marketing
Asset type: post quadrado Instagram, 1:1
Input images: Imagem 1 é a logo oficial do Sharebook. Use como referência visual de marca.
Primary request: <pedido>
Brand voice: acolhedora, simples e confiável; clareza primeiro.
Visual identity: azul Sharebook #29abe2 como acento principal; #ff4081 só como destaque raro; contraste forte; respiro.
Scene/backdrop: <cena concreta ligada a leitura/conhecimento/doação>
Composition: hierarquia clara, texto legível, margens seguras, peça pronta para Instagram.
Text requirements: <texto exato>. Não adicionar texto extra, watermark ou marcas falsas.
Quality: profissional, polido, coerente com Sharebook.
```

## Hero ou asset de frontend

```text
Use case: product-mockup or stylized-concept
Asset type: imagem de apoio para frontend
Input images: Logo Sharebook como referência visual quando fizer sentido.
Primary request: <pedido>
Frontend context: a imagem apoia a interface; UI funcional, botões e textos críticos serão código.
Visual identity: #29abe2 como acento; evitar poluição; estética humana e confiável.
Composition: deixar áreas de respiro se houver sobreposição de texto no frontend.
Quality: asset limpo, utilizável em layout responsivo.
```
